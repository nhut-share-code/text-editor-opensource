2. Cài Đặt Nhanh Trong 3 Bước

Chỉ mất chưa đầy 30 giây để biến bất kỳ thẻ <textarea> nào thành trình soạn thảo chuyên nghiệp.

1
Nhúng file CSS vào thẻ <head>

Đảm bảo bạn tải file CSS trước các nội dung hiển thị.

HTML / Blade 
<!-- CSS Rich Text Editor -->
<link rel="stylesheet" href="css/rich-text-editor.css">
2
Nhúng file JS trước thẻ đóng </body>

Script chứa toàn bộ logic xử lý thao tác văn bản và tự động quét các thẻ textarea.

HTML / Blade 
<!-- JS Rich Text Editor -->
<script src="js/rich-text-editor.js"></script>
3
Gắn class rich-editor vào thẻ <textarea>

Trình soạn thảo sẽ tự động nhận diện và khởi tạo giao diện thay thế.

HTML 
<textarea name="noi_dung" class="rich-editor" placeholder="Nhập nội dung bài viết..."></textarea>
💡
Xong ngay! Trình soạn thảo có cơ chế tự khởi tạo (Auto-init) tự động quét tất cả thẻ <textarea class="rich-editor"> khi DOM sẵn sàng mà bạn không cần phải viết thêm một dòng JavaScript nào.

4. Tích Hợp Chuẩn Vào Dự Án Laravel

Hướng dẫn đưa vào Layout chính và sử dụng trong các file Blade view.

A. Đưa vào Layout chính (Ví dụ: resources/views/layouts/admin.blade.php)

resources/views/layouts/admin.blade.php 
<!DOCTYPE html>
<html lang="vi">
<head>
    <meta charset="UTF-8">
    <title>@yield('title', 'Admin Dashboard')</title>

    <!-- 1. CSS Rich Text Editor -->
    <link rel="stylesheet" href="{{ asset('css/rich-text-editor.css') }}">
</head>
<body>
    <main>
        @yield('content')
    </main>

    <!-- 2. JS Rich Text Editor -->
    <script src="{{ asset('js/rich-text-editor.js') }}"></script>
    @stack('scripts')
</body>
</html>

B. Sử dụng trong Form Tạo Mới / Cập Nhật (Ví dụ: Bài Viết / Tài Liệu)

form.blade.php 
<form action="{{ route('admin.posts.store') }}" method="POST">
    @csrf
    
    <div class="mb-3">
        <label class="form-label fw-bold">Nội dung chi tiết bài viết:</label>
        <textarea 
            name="noi_dung" 
            class="form-control rich-editor" 
            data-height="280px" 
            placeholder="Soạn thảo văn bản, định dạng tiêu đề, chèn ảnh, bảng biểu...">{{ old('noi_dung', $post->noi_dung ?? '') }}</textarea>
    </div>

    <button type="submit" class="btn btn-success">Lưu Bài Viết</button>
</form>

C. Hiển thị nội dung ra trang người dùng (Frontend)

Vì nội dung được lưu dưới dạng HTML (chứa thẻ <p>, <img>, <table>), bạn hãy dùng cú pháp {!! ... !!} của Blade:

show.blade.php 
<!-- Nhớ kèm css của editor nếu muốn giữ nguyên style callout, bảng biểu -->
<div class="post-detail-content rte-editor-area" style="border: none; padding: 0;">
    {!! $post->noi_dung !!}
</div>

5. Các Thuộc Tính Cấu Hình (HTML Data Attributes)

Dễ dàng tùy chỉnh cách thức hiển thị của từng khung soạn thảo qua các thuộc tính HTML.

Thuộc tính Kiểu dữ liệu Mặc định Mô tả chi tiết
class="rich-editor" Class - Class kích hoạt tự động quét và gắn trình soạn thảo.
data-rich-editor Attribute - Thuộc tính kích hoạt thay thế cho class.
data-height="300px" String 260px Chiều cao tối thiểu của vùng soạn thảo văn bản (VD: 200px, 350px).
placeholder="..." String Nhập nội dung... Văn bản hướng dẫn hiển thị mờ khi khung chưa có dữ liệu.
name="..." String - Tên trường khi gửi qua HTTP POST Form thông thường.

6. Bảng Hàm JavaScript (Programmatic API)

Khi bạn cần điều khiển trình soạn thảo bằng JavaScript (Ajax, Fetch, Modal, SPA).

JavaScript 
// Cách 1: Khởi tạo thủ công cho 1 textarea
const editor = new RichTextEditor('#myTextarea', {
    height: '320px',
    placeholder: 'Nhập bài viết của bạn...'
});

// Cách 2: Lấy instance đã được khởi tạo trước đó
const editor = RichTextEditor.getInstance('#myTextarea');
Tên phương thức (Method) Tham số Chức năng
getContent() - Trả về chuỗi mã HTML hiện tại trong khung soạn thảo.
setContent(html) html: string Gán nội dung HTML mới vào editor và tự động đồng bộ sang textarea.
insertHTML(html) html: string Chèn một đoạn mã HTML hoặc văn bản vào ngay tại vị trí con trỏ chuột.
syncToTextarea() - Ép đồng bộ giá trị hiện tại sang thẻ <textarea> gốc.
focus() - Đặt con trỏ và kích hoạt vùng soạn thảo.
toggleDarkMode() - Bật hoặc tắt giao diện chế độ tối (Dark Mode).
toggleFullscreen() - Bật hoặc thoát chế độ toàn màn hình.
toggleSource() - Chuyển đổi giữa giao diện trực quan và xem mã nguồn HTML thô.
openPreview() - Mở hộp thoại (Modal) xem trước bài viết dạng trang in chuẩn.
exportWordDocument() - Tự động tải về file tài liệu định dạng Microsoft Word (.doc).

7. Cơ Chế Two-Way Sync Siêu Việt Đặc biệt

Không cần phải nhớ gọi hàm đồng bộ thủ công - Mọi thứ diễn ra tự động 100%.

Nhiều trình soạn thảo lớn (như TinyMCE hay CKEditor) gặp vấn đề rất khó chịu: khi bạn gán giá trị bằng JavaScript textarea.value = 'nội dung mới' (ví dụ khi load dữ liệu sửa qua Ajax), khung soạn thảo trực quan sẽ không đổi trừ khi bạn gọi hàm chuyên biệt của thư viện đó.

Rich Text Editor này đã được tích hợp sẵn kỹ thuật Property Interceptor Hook (can thiệp trực tiếp vào HTMLTextAreaElement.prototype):

JavaScript 
// Khi tải dữ liệu bài viết từ Ajax về để hiển thị vào form chỉnh sửa:
fetch('/api/posts/1')
    .then(res => res.json())
    .then(data => {
        // CHỈ CẦN GÁN BÌNH THƯỜNG NHƯ VỚI TEXTAREA THÔNG THƯỜNG!
        document.getElementById('edit_post_noi_dung').value = data.noi_dung;
        
        // >>> Khung soạn thảo trực quan sẽ TỰ ĐỘNG nhận và hiển thị ngay lập tức!
    });
📌
Khi người dùng gõ phím bên trong khung soạn thảo, editor cũng tự động bắn ra sự kiện input và change trên textarea, giúp các script Validation form luôn nhận được giá trị mới nhất.

8. Hoạt Động Trong Bootstrap Modal

Xử lý form tạo mới hoặc chỉnh sửa nằm trong cửa sổ popup Bootstrap Modal.

Khi đặt trong Bootstrap Modal, editor đã được tối ưu sẵn thuộc tính CSS min-width: 0 và box-sizing: border-box để không bao giờ làm vỡ kích thước popup modal.

Blade & JavaScript 
<!-- Khi mở Modal để sửa bài viết và gán dữ liệu qua JS -->
<script>
function openEditPostModal(post) {
    document.getElementById('edit_post_id').value = post.id;
    document.getElementById('edit_post_tieu_de').value = post.tieu_de;
    
    // Gán dữ liệu vào textarea có class rich-editor
    document.getElementById('edit_post_noi_dung').value = post.noi_dung || '';

    // Mở Modal Bootstrap 5
    const modal = new bootstrap.Modal(document.getElementById('editPostModal'));
    modal.show();
}
</script>

9. Xử Lý Sự Cố Thường Gặp (FAQ)

Giải đáp các câu hỏi thường gặp khi tích hợp vào dự án.

1. Hình ảnh upload được lưu trữ ở đâu?

Mặc định editor đọc file từ máy tính người dùng và chuyển thành chuỗi ảnh Base64 (Data URI) trực tiếp gắn vào thẻ <img src="data:image/png;base64,...">. Chuỗi này được lưu thẳng vào database (cột TEXT hoặc LONGTEXT) mà không cần cài đặt thêm API upload server phức tạp!

2. Tôi có thể đổi màu chủ đạo (Theme Color) sang màu khác không?

Hoàn toàn được! Bạn chỉ cần ghi đè biến CSS --rte-primary trong file CSS của mình:
:root { --rte-primary: #2563eb; /* Đổi sang màu xanh dương */ }

3. Giao diện trên điện thoại có bị tràn viền không?

Không! Editor đã được tối ưu hóa toàn diện: thanh Menubar và Toolbar tự động xuống dòng linh hoạt (flex-wrap: wrap), kích thước nút co nhỏ theo chuẩn màn hình điện thoại dưới 768px và 480px.

4. Khi form submit thì dữ liệu có bị mất không?

Trước khi form gửi đi (sự kiện submit), editor luôn tự động chạy hàm syncToTextarea() để đảm bảo 100% nội dung mới nhất đã nằm trọn vẹn trong <textarea>.
